# 🏡 펜션 파인더 (Pension Finder)

> 서울 근교, 전철 타고 놀러갈 수 있는 펜션을 찾아주는 작은 파이프라인이에요.
> "가평·청평·강촌·양평... 역에서 가까운 곳 중에 8~10명 놀기 좋은 데 없나?" 라는 질문에서 시작했습니다 🚂✨

경춘선·중앙선 권역의 펜션 후보를 TourAPI + 네이버 지역검색으로 긁어모으고,
역 접근성 점수를 매겨 지도로 보여줘요. 여기에 인원·가격·후기처럼 API로는 못 구하는 정보를
직접 채워 넣으면, 우리 상황(8~10인 단체, 깨끗하고 친절한 곳 선호)에 맞는 최종 순위가 나옵니다.

<br>

## ✨ 이 친구가 할 수 있는 일

- 🔎 **TourAPI + 네이버 지역검색**으로 경춘선·중앙선 권역 펜션 후보를 자동으로 모아요
- 🚉 역까지 직선거리 · 운행 횟수 · ITX 정차 여부로 **역 접근성 점수**를 매겨요
- 🗺️ 결과를 **지도(HTML)** 로 바로 볼 수 있어요
- 👨‍👩‍👧‍👦 **인원(8~10명) 조건**과 🧼 **후기 키워드("깨끗", "친절")** 가점을 반영해요
- ✍️ 가격 · 인원 · 후기처럼 공식 API로 못 구하는 정보는 **CSV로 손쉽게 손질**할 수 있어요
- 📍 검색으로 안 걸리는 "우리끼리 아는 그 펜션"도 **수동으로 후보 추가** 가능해요
- 💌 최종 후보를 **예쁜 요약 페이지**로 만들어서 단톡방에 공유할 수 있어요

<br>

## 🧭 한눈에 보는 흐름

```
1️⃣ TourAPI + 네이버 지역검색으로 후보 수집
        ↓
2️⃣ 역까지 거리·열차 접근성으로 1차 점수 매기기 (pipeline_v1.py)
        ↓
3️⃣ 상위 후보만 골라 가격·인원·후기 손으로 채우기 (data/manual_overrides.csv)
        ↓
4️⃣ 최종 점수 계산 + 지도 생성 (pipeline_v2.py)
        ↓
5️⃣ 카톡방에 공유할 요약 페이지 만들기 (data/share_summary.html)
```

<br>

## 🔑 API 키, 이렇게 받아오세요

이 프로젝트는 아래 3종 세트 키를 씁니다. 없어도 괜찮아요 — 없으면 자동으로 샘플 데이터로 돌아가서
파이프라인 전체 흐름을 먼저 구경할 수 있거든요.

| API | 어디서 받나요 | 왜 필요해요 |
|---|---|---|
| 🏞️ TourAPI | data.go.kr → `한국관광공사_국문 관광정보 서비스_GW` | 펜션 시설 정보(취사·바비큐 등) |
| 📍 네이버 지역검색(HUB) | 네이버클라우드플랫폼 콘솔 → NAVER API HUB | 펜션 이름·주소·좌표 검색 |
| 🚆 철도공사 열차운행정보 | data.go.kr → `한국철도공사_열차운행정보` | 역 접근성(운행 횟수·소요시간) 계산 |

> 💡 **Tip**: `.env.example`을 복사해서 `.env`로 이름 바꾸고 발급받은 키를 채워 넣으면 끝!
> ```bash
> cp .env.example .env
> ```
> `.env`는 `.gitignore`에 이미 포함돼 있어서 실수로 git에 올라갈 걱정은 안 하셔도 돼요.

## 🚀 실행해보기

```bash
pip install -r requirements.txt
```

### STEP 1. 역세권 후보 쫙 훑어보기

```bash
python pipeline_v1.py
```

`config.py`의 `CANDIDATE_WEEKENDS`에 적어둔 후보 주말별로 지도가 하나씩 만들어져요.
(`data/v1_map_<날짜>.html`) 역에서 가까운 순서대로 점수가 매겨진 상태예요.

### STEP 2. 우리 여행에 딱 맞게 다듬기

```bash
python pipeline_v2.py
```

처음 실행하면 `data/manual_overrides.csv`라는 빈 템플릿이 생겨요. 여기에 발품(?) 판 정보를
채워 넣고 다시 실행하면 최종 순위 + 지도(`data/v2_final_map.html`)가 완성됩니다.

| 컬럼 | 뭘 적나요 |
|---|---|
| `price_per_night` | 1박 가격 |
| `capacity` | 인원 (`10`처럼 숫자 하나, 또는 `8~12`처럼 범위도 OK) |
| `availability_note` | 예약 가능 여부, 객실 구성 등 자유 메모 |
| `review_score` | 후기 평점 (0~5) |
| `review_note` | 후기에서 확인한 특징 자유 메모 |
| `reservation_url` | 예약 페이지 링크 |

> 🧼 **"깨끗하다", "친절하다"가 좋아요**
> `review_note`에 이 단어가 들어있으면 자동으로 가점이 붙어요. 원하는 키워드는
> `config.py`의 `GOOD_REVIEW_KEYWORDS`에서 자유롭게 바꿀 수 있어요.
>
> 👨‍👩‍👧‍👦 **몇 명이 가나요?**
> `config.py`의 `MIN_CAPACITY` / `MAX_CAPACITY`로 인원 조건을 조절해요. 기본값은 8~10명!
> 인원 범위 밖이거나 정보가 없으면 최종 후보에서 자동으로 빠집니다.

<br>

## 📍 검색에 안 걸리는 펜션도 넣고 싶다면

지인 추천이나 블로그에서 발견한 "여기 좋대!" 펜션은 검색 결과에 아예 없을 수도 있어요.
그럴 땐 `pipeline_v2.py`의 `MANUAL_EXTRA_CANDIDATES` 리스트에 이름/주소/좌표만 추가해주면
자동으로 역까지 거리·접근성 점수까지 계산해서 후보에 끼워줍니다.

```python
MANUAL_EXTRA_CANDIDATES = [
    {"source": "manual", "name": "가평 연인벨리펜션", "address": "경기 가평군 북면 백둔로467번길 5-9",
     "lat": 37.9024387, "lng": 127.4586441},
]
```

> 🚗 역에서 좀 멀어도 "왕복 픽업 서비스"가 있는 곳들이 은근 많아요.
> 역접근성 점수는 정직하게 낮게 나오지만, 그래도 후보에는 남겨두고 다른 조건으로 비교할 수 있어요.

반대로 이미 나온 후보 중에 "여긴 진짜 아니야" 싶은 곳은
`EXCLUDED_CANDIDATE_NAMES`에 이름만 적어두면 다음 실행부터 자동으로 걸러져요.

<br>

## 💌 카톡방에 공유하기

최종 후보들을 예쁘게 정리한 요약 페이지가 `data/share_summary.html`에 있어요.
펜션 이름 · 1박 가격 · 최대 인원이 한눈에 들어오도록 카드 형태로 꾸며져 있고,
브라우저로 열어서 바로 확인하거나 링크로 공유할 수 있어요.

> 🔗 **카톡에 링크 붙여넣을 때 팁**
> GitHub에 올린 파일을 `htmlpreview.github.io`로 공유하면, 카톡 인앱 브라우저가
> 링크 중간의 `https://`를 보고 멋대로 잘라먹는 경우가 있어요. 이럴 땐 안쪽 URL을
> 퍼센트 인코딩(`https%3A%2F%2F...`) 해주면 링크 하나로 깔끔하게 인식됩니다.

<br>

## ⚠️ 알아두면 좋은 것들

1. **`collectors/korail.py`의 `STATION_CODE_MAP`은 아직 자리표시자예요.**
   `fetch_station_codes()`로 실제 역코드(가평·청평·강촌·대성리·상천·굴봉산·백양리·양평·용문·청량리·상봉)를
   확인해 채워 넣어야 열차 운행 정보가 제대로 반영돼요. 지금은 이 값이 비어있어도
   거리 기준 점수만으로 파이프라인이 끝까지 돌아가도록 만들어뒀어요.
2. **직선거리는 참고용이에요.** 최종 후보 3~5개로 좁힌 뒤엔 카카오맵 길찾기 API로
   실제 도보/대중교통 시간까지 확인해보는 걸 추천해요.
3. **가격 · 실시간 예약 · 후기는 공식 API에 없어요.** 야놀자·여기어때 같은 예약 플랫폼엔
   있지만 공개 API가 없고 스크래핑은 이용약관 위반 소지가 있어서, 상위 후보만 추려 손으로
   확인하는 방식을 택했어요.
4. **네이버 지역검색은 한 번에 최대 5건까지만** 돌려줘요 (네이버 정책).

<br>
