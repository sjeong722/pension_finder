# 서울 근교 전철 접근 펜션 후보 파이프라인

TourAPI + 네이버 지역검색(HUB) + 철도공사 열차운행정보를 조합해
경춘선·중앙선 권역의 펜션 후보를 찾고, 열차 접근성 점수를 매겨 지도로 시각화합니다.

## 0. 키 없이 먼저 테스트하기 (추천)

API 키 승인을 기다리는 동안에도 파이프라인 전체를 검증할 수 있습니다.
`.env` 파일이 없거나 키 값이 비어있으면 자동으로 `data/sample/` 안의 샘플 데이터로 동작합니다.

```bash
pip install -r requirements.txt
python pipeline_v1.py   # 샘플 데이터로 역접근성 지도 생성
python pipeline_v2.py   # 수동입력 템플릿 생성 -> 채운 뒤 재실행하면 최종 지도 생성
```

## 1. 실제 API 키 설정

`.env.example`을 복사해 `.env`로 이름을 바꾸고 발급받은 키를 채워 넣으세요.
`.env`는 `.gitignore`에 포함돼 있어 git에 올라가지 않습니다.

```bash
cp .env.example .env
```

| API | 발급처 |
|---|---|
| TourAPI | data.go.kr → '한국관광공사_국문 관광정보 서비스_GW' |
| 네이버 지역검색 | 네이버클라우드플랫폼 콘솔 → NAVER API HUB |
| 철도공사 열차운행정보 | data.go.kr → '한국철도공사_열차운행정보' |

## 2. 실행 전 반드시 확인해야 하는 것

1. **`collectors/korail.py`의 `STATION_CODE_MAP`** — 지금은 자리표시자입니다.
   `fetch_station_codes()`로 실제 역코드(가평·청평·강촌·대성리·상천·굴봉산·백양리·양평·용문·청량리·상봉)를 확인해 채워 넣으세요.
2. **`collectors/korail.py`의 엔드포인트 경로/파라미터/필드명** — 활용신청 승인 후 마이페이지에서 제공되는
   공식 문서로 반드시 재확인하세요. 승인 전에는 공개 문서만으로 정확한 스펙을 확인할 방법이 없습니다.

## 3. v1 vs v2

- **v1** (`pipeline_v1.py`): TourAPI + 네이버 지역검색으로 모은 전체 후보를, 두 후보 주말
  (`config.py`의 `CANDIDATE_WEEKENDS`) 각각에 대해 역 접근성(거리·운행횟수·ITX정차·서울 기준 소요시간)으로
  점수를 매겨 지도로 만듭니다. 날짜별 상위 5개 비교도 콘솔에 출력됩니다.
- **v2** (`pipeline_v2.py`): v1 상위 후보(주말별 상위 8개, 중복 제거)만 골라
  - TourAPI 시설 정보(취사·바비큐 가능 여부)
  - `data/manual_overrides.csv`에 수동으로 채운 가격·인원·예약가능여부·후기
  를 더해 최종 추천 점수를 계산합니다. 처음 실행하면 이 CSV의 빈 템플릿이 자동 생성되니,
  채운 뒤 다시 실행하세요. (`data/manual_overrides.example.csv`에 작성 예시가 있습니다.)

## 4. 왜 가격·예약가능여부·후기는 자동 수집하지 않는가

TourAPI와 네이버 지역검색 어디에도 실시간 가격·예약 가능 여부·후기/청결도 필드가 없습니다.
이 데이터는 실제로는 야놀자·여기어때 같은 예약 플랫폼에 있는데, 공식 오픈API가 제공되지 않고
스크래핑은 각 사이트 이용약관 위반 소지가 있어 이 프로젝트에서는 다루지 않습니다.
대신 v1에서 걸러진 상위 후보만 수동으로 전화/사이트 확인해 CSV에 채우는 흐름으로 설계했습니다.

## 5. 향후 개선 여지 (지금은 미포함)

- **실제 도보/버스/택시 접근성**: 역-펜션 직선거리(현재 3km 필터)는 1차 필터일 뿐입니다.
  최종 후보에 대해 카카오맵 길찾기 API(별도 키 필요)로 실제 이동시간을 검증하는 걸 추천합니다.

## 6. 점수 기준 조정하기

- v1 역접근성: `pipeline_v1.py`의 `score_pension()`
- v2 최종점수(역접근성 60% + 쾌적함 40% 가중합): `pipeline_v2.py`의 `compute_comfort_score()`와 `run_pipeline()` 내부 가중치

## 7. 알려진 제약

- 네이버 지역검색은 한 번 호출에 최대 5건까지만 반환됩니다 (네이버 정책).
- 철도공사 '운행계획' 데이터의 미래 시점 조회 가능 범위가 명확히 문서화되어 있지 않으니,
  10월 날짜로 먼저 테스트 호출해서 데이터가 나오는지 확인하세요.
